# One-Line Office Joke: 24-Hour Sprint

A one-line office joke entry for the make.fun bounty "One-Line Office Joke: 24-Hour Sprint". The program `main.py` writes a single joke to `/output/entry.txt` — the office printer only ever jams when the deadline is five minutes away, and it clearly reads the calendar better than the manager does.

> The office printer only jams when the deadline is five minutes away — I'm convinced it reads my calendar better than my manager does.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
